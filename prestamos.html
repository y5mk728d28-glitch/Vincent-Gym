Cómo se generan los IDs
ID de cliente (fijo de por vida, es su código de acceso): Iniciales del nombre + año de nacimiento (2 díg.) + estado + 5 dígitos al azar.
Ej. MR90NV12345 = Miguel Rodriguez, nacido en 1990, Nevada.

Folio de préstamo: Estado del cliente + año del préstamo + categoría por monto + 5 dígitos al azar.
Categoría: C = menos de $100 · M = $100–$9,999 · D = $10,000 o más.
Ej. NV26M12345 = Nevada, 2026, categoría M ($100–$9,999).

Ambos se generan automático al crear el cliente o el préstamo — no necesitas hacer nada. Si un cliente o préstamo es de antes de esta función, se le asigna el nuevo formato la próxima vez que abras la app. Puedes personalizar el ID de un cliente cuando quieras desde "Editar cliente" — si ya le habías compartido el código anterior, avísale del cambio.
Respaldo de datos
Esta app guarda todo en este dispositivo (sin nube todavía). Exporta un respaldo con frecuencia.
Aviso legal: los contratos generados por esta app son plantillas de conveniencia y no constituyen asesoría legal. Prestar dinero a residentes de otros estados puede requerir licencia en el estado del cliente, y las tasas de interés máximas permitidas varían por estado. Consulta a un abogado licenciado antes de usar estos contratos.
